# وَصْل — منصة الاتصالات المؤسسية السيادية

واجهة تشغيلية عربية لمنصة اتصالات ذاتية الاستضافة تجمع الدردشة والقنوات والاجتماعات والمكالمات والملفات والإدارة في تجربة موحدة ذات علامة بيضاء، وتبدأ ببوابة دخول سينمائية أصلية مستضافة محلياً.

## التشغيل

افتح `index.html` مباشرة، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## نطاق النسخة الحالية

- واجهة متجاوبة للحاسوب والجوال.
- بوابة دخول سينمائية بخلفية فضائية أصلية وبطاقات زجاجية عائمة.
- تدفق تسجيل دخول تجريبي وتسجيل خروج للعرض.
- قنوات ورسائل مباشرة ومرفقات وإرسال رسائل تفاعلي.
- مركز اجتماعات مع نافذة معاينة قبل الانضمام.
- أقسام للمكالمات والملفات والامتثال.
- هوية عربية قابلة لإعادة التسمية بالكامل.

هذه نسخة واجهة منتج وليست بعدُ خادماً إنتاجياً. البناء الإنتاجي يتطلب خدمات هوية وصلاحيات، تخزيناً كائنياً، قاعدة بيانات، WebSocket، WebRTC/SFU، بحثاً، إشعارات، مراقبة، نسخاً احتياطياً وتطبيقات جوال.

## معمارية الإنتاج المقترحة

- البوابة والهوية: Keycloak + OIDC/SAML/LDAP.
- الرسائل الفورية: Matrix/Synapse أو خدمة Go مخصصة فوق WebSocket وPostgreSQL.
- الاجتماعات: LiveKit أو Jitsi مع Coturn، جميعها داخل الشبكة الخاصة.
- الملفات: MinIO مشفّر + ClamAV + سياسات احتفاظ.
- البحث: OpenSearch داخل المؤسسة.
- الأحداث: NATS JetStream، والمراقبة Prometheus/Grafana/Loki.
- النشر: Kubernetes داخلي متعدد العقد مع Harbor وVault ونسخ احتياطي منفصل.

## ملاحظة مهمة

عبارة «أكثر من 1000 ميزة» ينبغي تحويلها إلى سجل قدرات قابل للقياس، ثم إطلاقها على مراحل. البداية الموصى بها: 40–60 قدرة أساسية، يتبعها الأمن والامتثال والتكاملات والإدارة المتقدمة.
